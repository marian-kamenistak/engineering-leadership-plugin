# Grow Your Value

Two scores and a profile rewrite for engineering leaders and developers who want to earn more.

| Skill | Input | You get |
|---|---|---|
| `market-value-multiplier` | Your role and twelve answers (or your CV) | Your **VMS** (Value Multiplicator Score) from 0.4 to 1.7, its name on a nine-step scale, the salary it implies, and the three steps that raise it most |
| `digital-footprint-multiplier` | One LinkedIn profile URL | How you look to a recruiter, a hiring manager or an AI screening tool, from public evidence only: a multiplier from 0.4 to 1.7 and a plan |
| `linkedin-profile-boost-advisor` | One LinkedIn profile URL (or pasted text) and the role you want next | A plan you can apply in one evening: rewritten headline, About and experience (outcomes, not outputs), Featured, skills, keywords, and a 2-week posting starter. Run the footprint score first if you want the number |

The web version of the VMS runs at [marian.coach/vms](https://www.marian.coach/vms).

## Install

```
/plugin marketplace add marian-kamenistak/engineering-leadership-plugin
/plugin install grow-your-value@marian-coach
```

Then ask: "what is my VMS?", "score my digital footprint: <LinkedIn URL>", or "rewrite my LinkedIn for a CTO search".

Run the footprint score and the rewrite on yourself, or on someone who asked you to. It reads public pages only.
